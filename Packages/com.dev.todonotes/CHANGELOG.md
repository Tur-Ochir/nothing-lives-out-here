# Changelog

All notable changes to the "Editor Tasks & Notes Manager" package will be documented in this file.

## [1.0.0] - 2026-08-26
### Added
- Initial release of Editor Tasks & Notes Manager package.
- To-Do List tab with priority levels, categories, status tracking, object linking, and search/filter.
- Notes tab with master-detail navigation, pinned notes, color labeling, and multi-asset references.
- Scratchpad tab with auto-save and conversion helpers.
- In-scene `SceneTaskMarker` component and 3D gizmo visualization with Scene Pins navigation tab.
- Markdown and JSON export/import utilities.
- Settings view for database configuration and custom category management.
